# Pilot mode and demo link
Crew Call is in a small pilot at the moment, so only invited testers can sign in. It opens to every LFS student soon. || Сейчас Crew Call работает в небольшом пилотном режиме, поэтому войти могут только приглашённые тестировщики. Скоро он откроется для всех студентов LFS. || يعمل Crew Call حاليًا في مرحلة تجريبية محدودة، لذا لا يمكن تسجيل الدخول إلا للمختبرين المدعوين. سيُفتح قريبًا لجميع طلاب LFS.

Admins, the people on the pilot list and guests that members invite can sign in. Anyone else is told Crew Call opens soon. || Войти могут админы, люди из пилотного списка и гости, приглашённые участниками. Остальные увидят, что Crew Call скоро откроется. || يمكن للمشرفين والأشخاص المدرجين في القائمة التجريبية والضيوف الذين يدعوهم الأعضاء تسجيل الدخول. أما الآخرون فيُبلَّغون بأن Crew Call سيُفتح قريبًا.

The code is kept on GitHub and the site is hosted on GitHub Pages. The database and sign-in run on Supabase's hosted service, although Supabase's own software is open source. Emails go through whichever sender the admins set up. We only use free plans, and Crew Call can move away from any of them. || Код хранится на GitHub, а сайт размещён на GitHub Pages. База данных и вход работают на хостинге Supabase, хотя само ПО Supabase открытое. Письма отправляются через сервис, который настроили админы. Мы пользуемся только бесплатными тарифами, и Crew Call может уйти с любого из них. || يُحفظ الرمز البرمجي على GitHub ويُستضاف الموقع على GitHub Pages. تعمل قاعدة البيانات وتسجيل الدخول على خدمة Supabase المستضافة، مع أن برنامج Supabase نفسه مفتوح المصدر. تُرسل الرسائل عبر خدمة الإرسال التي يعدّها المشرفون. لا نستخدم إلا الخطط المجانية، ويمكن لـ Crew Call الانتقال عن أي منها.
