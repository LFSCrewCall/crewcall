The code is kept on GitHub and the site is hosted on GitHub Pages. The database and sign-in run on Supabase's hosted service, although Supabase's own software is open source. Emails go through whichever sender the admins set up. We only use free plans, and Crew Call can move away from any of them. || 程式碼存放在 GitHub，網站由 GitHub Pages 託管。資料庫和登入使用 Supabase 的託管服務，不過 Supabase 本身的軟體是開源的。電郵經由管理員設定的寄件服務寄出。我們只使用免費方案，Crew Call 隨時可以改用其他服務。 || Le code est sur GitHub et le site est hébergé sur GitHub Pages. La base de données et la connexion passent par le service hébergé de Supabase, même si le logiciel de Supabase est lui-même open source. Les e-mails partent par le service d’envoi choisi par les admins. Nous n’utilisons que des offres gratuites, et Crew Call peut quitter chacune d’elles. || El código está en GitHub y la web se aloja en GitHub Pages. La base de datos y el inicio de sesión funcionan con el servicio alojado de Supabase, aunque el software de Supabase es de código abierto. Los correos salen por el servicio de envío que configuren los administradores. Solo usamos planes gratuitos, y Crew Call puede dejar cualquiera de ellos.
