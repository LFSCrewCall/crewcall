The code is kept on GitHub and the site is hosted on GitHub Pages. The database and sign-in run on Supabase's hosted service, although Supabase's own software is open source. Emails go through whichever sender the admins set up. We only use free plans, and Crew Call can move away from any of them. || कोड GitHub पर रखा है और साइट GitHub Pages पर होस्ट है। डेटाबेस और साइन इन Supabase की होस्टेड सर्विस पर चलते हैं, हालाँकि Supabase का अपना सॉफ़्टवेयर ओपन सोर्स है। ईमेल उसी सर्विस से जाते हैं जो एडमिन सेट करते हैं। हम सिर्फ़ फ़्री प्लान इस्तेमाल करते हैं, और Crew Call इनमें से किसी को भी छोड़ सकता है। || O código fica no GitHub e o site é hospedado no GitHub Pages. O banco de dados e o login rodam no serviço hospedado do Supabase, embora o software do próprio Supabase seja de código aberto. Os e-mails saem pelo serviço de envio que os admins configurarem. Só usamos planos gratuitos, e o Crew Call pode sair de qualquer um deles.
